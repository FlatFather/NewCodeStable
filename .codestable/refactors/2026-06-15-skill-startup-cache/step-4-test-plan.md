# 步骤 4 全量测试清单

## 测试目标

验证缓存优化后：
1. 所有技能正常启动
2. Read 调用次数显著减少
3. Token 节省效果符合预期

## 测试方法

### 自动化验证（AI 可执行）

1. **语法检查** — 验证所有 SKILL.md 文件格式正确
2. **引用完整性** — 验证所有引用的文件存在
3. **模式匹配** — 验证"缓存优化"段落格式一致

### 手动验证（需 HUMAN 执行）

1. **Feature 流程测试**
   - 启动 cs-feat-design（观察 Read 调用）
   - 继续 cs-feat-plan（观察是否复用上下文）
   - 继续 cs-feat-impl（观察是否复用上下文）
   - 继续 cs-feat-accept（观察是否复用上下文）
   - 预期：第一个技能 Read，后续技能输出"已复用上下文"

2. **Issue 流程测试**
   - 启动 cs-issue-report（观察 Read 调用）
   - 继续 cs-issue-analyze（观察是否复用上下文）
   - 继续 cs-issue-fix（观察是否复用上下文）
   - 预期：第一个技能 Read，后续技能输出"已复用上下文"

3. **Token 统计**
   - 对比优化前后的 Read 调用次数
   - 计算实际节省的 token 数量
