# feature-design 参考模板

本文件是 `cs-feat-design` 参考资料入口。为遵守单 md 文档不超过 500 行的项目约束，详细内容已按主题拆分：

- `reference-frontmatter.md` — `{slug}-design.md` frontmatter 与顶层节锚点
- `reference-writing-guide.md` — design 各节写作要求与 review 提示

使用规则：

- 起草 design 时先读 `reference-frontmatter.md` 和 `reference-writing-guide.md`。
- `{slug}-plan.md` / `{slug}-checklist.yaml` 模板不在本技能包内——那是 `cs-feat-plan` 的产出格式，由 `cs-feat-plan` 自己的文档承接，本技能不重复维护（避免跨包引用与内容 drift）。
- 本文件只作导航，不重复展开模板正文。
