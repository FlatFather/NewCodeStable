# Requirements

按复审优先级继续第二轮加固：

1. 增加 CI 执行统一质量门。
2. verify 必须检查仓库 Skill 源码，并独立验证本地安装漂移。
3. 增加 CCG task 生命周期机器校验。
4. 增加外部模型 backend preflight 与明确降级协议。
5. 增加 warning baseline 失效、重复和复审时间检查。
6. 逐步将关键路由规则从纯文案断言抽成可执行决策模型。
7. 改善 sync-skills 的平台/目标语义，支持显式 logical target 并报告 physical target。

不得改变 canonical artifacts 的最高权威地位；共享工具必须同步 cs-onboard source 与 repo-local copy；Markdown 不超过 500 行。
